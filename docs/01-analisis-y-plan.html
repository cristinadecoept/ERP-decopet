Plataforma de gestión de Decopet — análisis y plan

Documento de trabajo · 13 de septiembre de 2026 · privado

1. Lo que entiendo que quieres

Un sitio web privado (usuario y contraseña, desde computadora o celular) que sea el único lugar donde vive la información de Decopet. No es un programa contable: es el sistema con el que se opera la marca día a día, y que además te deja ver el negocio completo.

  • Reemplaza a Airtable como fuente central. Airtable queda solo para auditar, importar histórico y validar la transición; después se apaga para la operación diaria.
  • Los canales alimentan por detrás (Tina/WhatsApp, Shopify, Cashea, Meta). Nadie copia la misma información en dos sitios.
  • Dos experiencias distintas sobre los mismos datos: una para logística (simple, sin dinero) y una para ti (todo).
  • El centro es el cliente y su recompra. Especialmente el ciclo porche PRO → repuestos → packs, que hoy no se controla bien.
  • Todo es auditable: cada acción importante guarda quién y cuándo; cada número se puede abrir para ver qué órdenes, clientes o movimientos lo forman; ninguna estimación se presenta como hecho.
  • Los precios viven en el catálogo, no en el código; cada orden guarda el precio y la tasa BCV que se usaron ese día.
Qué pasa con lo que ya construí hoy. El prototipo de esta tarde fue útil para dos cosas que siguen valiendo: la limpieza e importación de tus 3 años de ventas (7.794 pedidos, nombres de producto y formas de pago unificados, cifras cuadradas con tu Excel de caja) y el catálogo con sus alias. Lo que este brief cambia es el modelo de datos (receptor distinto del cliente, packs y consumo, notas clasificadas, roles y permisos, historial de cambios, cuentas vs. utilidad) y el diseño. No voy a estirar el prototipo: lo correcto es rediseñar el esqueleto con este documento como base y reutilizar la importación.

5. Flujo de un repuesto que pertenece a un pack

La clave es separar cuatro cosas que hoy se mezclan: la compra del pack (una venta), el saldo del pack (unidades que Decopet le debe al cliente), la solicitud (el cliente pide uno) y la entrega (sale físicamente). Solo la primera es dinero.

  1. Compra. Orden normal con "Pack 3 repuestos". El sistema crea un pack activo del cliente: unidades totales 3, entregadas al momento X, saldo 3−X. (Necesito saber qué se entrega al momento: ¿ninguna, una, o a veces todas?)
  2. Solicitud. El cliente escribe (a Tina o a Ingrid). Se registra una solicitud de repuesto ligada al pack: fecha, tipo de entrega, dirección, notas. No se crea una venta. Aparece en Operaciones → "Repuestos de packs por entregar", con cliente, pack, total, entregados, restantes después de esta, fecha prevista, estado.
  3. Entrega. Se coordina y despacha como cualquier envío (pick-up, delivery o nacional). Al marcar entregado: saldo −1, inventario de repuestos −1, fecha real, quién entregó. (¿Se cobra el delivery de cada repuesto? Si sí, ese cobro sí es un movimiento de caja, pero no una venta de producto.)
  4. Cálculo de duración. Solo cuando hay una entrega anterior conocida: duración = fecha de esta entrega − fecha de la anterior. Se guarda con un nivel de confianza:
    • Alta: un solo porche, un perro, no tenía unidades previas, entregas registradas una por una.
    • Media: recibió varias unidades juntas (se reparte el tiempo entre ellas) o tenía unidades previas conocidas.
    • Baja: varios perros o porches, compró repuestos por otra vía, o dejó de usarlo un tiempo.
  5. Saldo en cero. El pack se cierra. Se genera una oportunidad ("podría necesitar un nuevo pack alrededor del día X") calculada con la duración promedio de ese cliente; si no tiene historial, con el promedio general del tamaño de porche, marcada como estimación.
Ejemplo A — entregas una por una. Compra pack de 3 el día 0 y recibe 1. Pide el segundo el día 34, el tercero el día 70, y recompra el día 101. Duraciones: 34, 36, 31 → promedio 33,7 días. Confianza alta si tiene un perro y no tenía unidades previas.
Ejemplo B — las tres juntas. Recibe las 3 el día 0 y recompra el día 101. El sistema muestra "≈ 33,7 días por repuesto (estimado)", confianza media: no sabemos si le sobró alguno o si alternó con paseos. Si además tenía unidades de antes, baja.

Con esto salen las métricas que pediste (duración por cliente, por tamaño, por número de perros, recompra a 30/60/90/120/180 días, clientes fuera de patrón, unidades a producir) siempre etiquetadas como confirmadas o estimadas.
